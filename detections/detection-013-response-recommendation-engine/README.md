\# Detection 013 - Automated Incident Response Recommendation Engine

\## Overview

Detection 013 adds automated response recommendations to the Automated SOC Detection \& Response Lab.

The engine consumes incident context generated by previous detections and recommends the next SOC actions based on:

\- Incident risk score

\- Incident risk level

\- SOC priority

\- Asset criticality

\- Containment status

\- SLA status

\- MITRE ATT\&CK context

\- Correlated activity

\- Case status

The output includes investigation actions, containment guidance, escalation decisions, evidence-collection actions, closure guidance, and an analyst summary.

\## Scenario 1 - Baseline Incident

Context:

```text

Risk Level:         MEDIUM

Priority:           P3

Containment:        SUCCESS

SLA Status:         WITHIN\_SLA

Asset Criticality:  MEDIUM

```

Result:

```text

Urgency:             STANDARD

Escalation Required: False

Escalation Level:    No Immediate Escalation

```

Recommended handling:

```text

Continue standard analyst investigation.

Validate that containment remains effective.

Review related activity before considering closure.

```

\---

\## Scenario 2 - Critical Incident with Failed Containment

Context:

```text

Risk Score:          75

Risk Level:          CRITICAL

Priority:            P2

Asset Criticality:   HIGH

Containment:         FAILED

SLA Status:          AT\_RISK

```

Result:

```text

Urgency:             IMMEDIATE

Escalation Required: True

Escalation Level:    L2/L3 Escalation

```

Containment recommendations include:

```text

Perform manual containment immediately

Validate endpoint and network isolation controls

Confirm whether suspicious activity remains active

```

\---

\## Scenario 3 - SLA Breach

The critical incident was then evaluated after the SLA deadline was exceeded.

Context:

```text

Risk Level:          CRITICAL

Containment:         FAILED

SLA Status:          BREACHED

```

Result:

```text

Urgency:             IMMEDIATE

Escalation Required: True

Escalation Level:    Management Escalation

```

The SLA breach takes escalation precedence and requires management attention in addition to the ongoing security investigation.

\## Null-Safe Context Handling

The engine safely handles optional context fields that may be missing or set to `null`.

For example:

```text

correlation: null

```

is treated as an empty context object rather than causing the response engine to fail.

This makes the recommendation workflow more resilient to incomplete upstream data.

\## Limitations

Current limitations include:

\- Static response logic

\- Local JSON input

\- No direct EDR isolation action

\- No approval workflow

\- No automatic ticket updates

\- No user-risk context

\- No vulnerability context

\- No environment-specific playbooks

\- No automatic Wazuh API ingestion

\- No real case-management platform integration
